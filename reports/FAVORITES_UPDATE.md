# 즐겨찾기 명칭·이동 범위 · 1.0.17+18

2026-11-16. 하단 탭·목록 제목·추가/해제 도움말·백업 안내의 `별표`를 `즐겨찾기`로 변경했다. 별 모양 아이콘과 기존 저장 데이터는 유지한다.

즐겨찾기 탭에서 연 단어 상세는 **전체 즐겨찾기 단어 안에서만 이전/다음으로 이동**한다. 급수·검색·품사 필터나 현재 페이지로 범위를 줄이지 않고 기존 급수별 학습 순서를 따른다. 상세 제목에는 즐겨찾기 내 위치와 개수를 표시한다. 일반 단어 목록·이어서 학습·예문 링크에서 연 상세의 전체 카탈로그 이동은 유지한다.

상세에서 즐겨찾기를 해제하면 현재 카드와 정답 표시를 유지하되 이후 이동 대상에서는 제외한다. 해제한 현재 단어에는 즐겨찾기 순번을 표시하지 않는다. 즐겨찾기가 한 개뿐이거나 모두 해제되면 해당 방향의 이동 버튼을 비활성화하며, 다시 추가하면 즉시 반영한다. 저장에 성공한 상태만 이동 대상에 반영한다.
