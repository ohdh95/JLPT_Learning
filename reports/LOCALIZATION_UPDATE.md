2026-10-28, Linux / Flutter 3.47.8 / Dart 3.13.7 / JDK 17 / Android API 36 x86_64.

단어 뜻은 모두 입력했다. 표제어·읽기·원본 영어 풀이를 함께 보고 한국어 학습 뜻을 작성했으며 다의어의 모든 뜻을 망라하는 사전은 아니다. 원본 stable ID와 급수별 단어 수를 유지했다. 한국어 표기에는 `훈 모일 음 회` 대신 기존 UI의 `모일 회` 표시를 사용한다.

한자는 libhangul hanja.txt의 훈음 후보와 Unicode 17.0 Unihan의 이체자·한국음을 대조했다. 대표 훈음 수동 교정 299자, libhangul 직접 1,967자, 편집한 이체자 대응 164자, Unihan 대응 112자다. 학습용 대표 훈음 선택이므로 다음자의 모든 음을 열거하지 않는다. 11,182개 단어–한자 연결에 훈음 누락이 없다. 보충 159자에 임의의 JLPT 급수/일본어 음독·훈독을 지정하지 않았다.

자동 한국음 대조는 **2,520자 일치, 21자 비교값 없음, 1자 불일치(涸)**다. 이는 음의 참고 자료 비교이며 훈·뜻·문맥의 독립 검수를 대신하지 않는다. 일본 국자나 일본에서 달라진 의미는 한국식 대표 훈과 차이가 있을 수 있다. 비교가 안 된 22자의 후보·대안·출처는 `localization-data-checks.json`에 남겼다.

## 검토 범위와 발견한 문제

- 공식 JMdict 218,969항목에서 연결 ID가 있는 7,800개 단어의 현재 의미와 표기/읽기 제한을 추출했다. 기존 표기·읽기·ID 검증 7,788개와 이 의미 추출 수는 서로 다르다.
- 영어 풀이 문자열이 겹치지 않는 후보 1,314개 중 단어 수준의 겹침도 적은 우선순위 234개와 별도 모호한 52개 항목의 현재 사전 뜻을 추가 대조했다. 이들은 중복될 수 있으며 1,314개를 모두 오류라고 판단한 것이 아니다.
- 예: 王子 → 왕자, 佚 → 편안함/한가로움, 一定(いちじょう) → 확실함, 地方(じかた) → 전통 공연 반주자 등의 읽기별 뜻을 교정했다. 兼ねて는 현재 사전에 맞춰 ‘이전부터; 진작; 미리’, 양태의 そう는 ‘~할 것 같음; ~해 보임’으로 수정했다.
- 원본 せっけん은 石鹸(비누)이 아닌 節倹에 연결되어 있어 **절검(節倹)**으로 명시했다. せめても 부사가 아닌 攻め手에 연결되어 **공격(攻め手)**으로 명시했다. 원본 항목의 의도·급수·예문 연결은 별도 검토가 필요하다.
- しいんと는 연결 사전의 死因과 맞지 않아 원문 부사에 맞춰 번역하고 ID/품사 충돌을 남겼다. 원본 ID를 임의 교체하지 않았다.
- 涸의 ‘마를 학’은 한국 한자 자료와 kKorean HAK를 참고했지만 Unihan kHangul의 ‘후’와 불일치한다. 전문 검토 전까지 draft다.
- 예문 「荷物が遅れた場合、特別な連帯保険がある。」는 영어 delay insurance와 일본어 連帯保険가 달라 **번역 보류**했다.

위 추가 이슈 7개는 `pipeline/localization/editorial_issues.json`과 DB `source_review`에 있다. 기존 미수록 한자 문제는 훈음 보충 후 ‘급수 미지정’ 문제로 갱신했고 원본 목록에 없다는 사실은 보존했다. 원본 표기·읽기 조합 미발견 21개, ID 충돌 2개, 품사 누락 11개는 별도 편집 검수가 남아 있다.

## 예문 진행 상태

- 로컬 M2M100으로 **13,713개 기계 번역 초안**을 생성했으나 품질 표본에서 ‘연’을 ‘고양이’, ‘모음 변화’를 ‘혈관 변화’로 옮기는 등 의미 오류를 발견했다. 이 파일은 **앱에 넣지 않았다**.
- 일본어·영어와 대조해 고친 242개 항목을 편집 후보에 저장했다. Tatoeba 직접 한국어 연결 64개도 포함해 확인·수정했다. 동일한 일본어 **및 영어** 문장에만 확대 적용하여 앱에는 284개를 반영했다.
- 앱 예문 번역의 급수별 수: N5 106, N4 35, N3 62, N2 38, N1 43. 아직 번역이 반영되지 않은 **13,434개**가 남는다.
- 원시 기계 번역은 `pipeline/localization/example_machine_drafts.jsonl`에 검수 자료로만 보관한다. 번역 완료 또는 검수 완료 수로 계산하지 않는다.
- 기존 Tatoeba 한국어 번역을 참고·수정한 문장은 원저자·문장 ID·원번역·CC BY 2.0 FR를 보존했다. 단어, 훈음, 예문 출처는 DB와 후보 JSONL에서 추적할 수 있다.

**독립된 사람 검수 완료는 단어 뜻·훈음·예문 모두 0개다.** AI 작성/대조 및 형식 검사를 사람 검수로 올리지 않았다. 작성분은 `draft`, 미작성 예문은 `not_provided`이며 `release_gate.py --strict`는 코드 2로 계속 차단한다.
