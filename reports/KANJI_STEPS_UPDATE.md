# 한자 연속 학습·화면 정리·외래어 가나 · 1.0.7+8

> 중간 버전 1.0.7의 기록입니다. 이후 사용자 요청으로 탐색 범위·이어서 학습·테스트 방식이 바뀌었습니다. 현재 전달 파일은 [1.0.8 보고서](LEARNING_FLOW_UPDATE.md)를 따릅니다.

2026-10-28 · Flutter 3.47.8 / Dart 3.13.7 / Android API 36 x86_64 에뮬레이터.

## 완료한 기능

- 한자 상세 하단에 고정 **이전 · 위치/전체 · 다음**을 추가했다. 한자 목록에서 열면 현재 급수와 검색 결과의 순서를 유지한다. 처음과 마지막에서는 해당 방향 버튼이 비활성화된다. 다른 한자로 이동하면 관련 단어를 접고 스크롤을 맨 위로 되돌린다.
- 단어 카드에서 한자를 열면 해당 단어의 구성 한자 순서로 이동한다. 예: 映画館의 画에서 다음을 누르면 館으로 이동한다. 돌아오면 원래 단어의 위치·임시 정답 표시·선택·별표·표시 설정을 유지한다.
- 한자 목록은 **선택한 급수만** 보여 준다. 신규/누적 전환 버튼을 제거했다. 각 칸에는 한자와 훈음만 표시하고 반복되는 급수 표기는 제거했다. 다섯 메뉴와 한자 검색은 유지한다.
- 단어 첫 화면의 홍보 문구·데이터 안내, 문법 첫 화면의 부가 안내, 문법/가나의 참고 자료, 가나의 하단 설명, 설정의 데이터 검수 현황 화면을 제거했다. 학습에 필요한 활용 규칙, 백업/복원과 필수 출처·라이선스 고지는 유지한다.
- 가나에 **외래어** 항목을 추가했다. ファ・フィ・フェ・フォ, ティ・ディ, トゥ・ドゥ, ヴァ・ヴィ・ヴ・ヴェ・ヴォ 등 33개를 가타카나와 한글 참고 발음으로 표시한다. 기본/탁음·반탁음/요음은 기존처럼 히라가나와 가타카나를 함께 표시한다.
- 이어서 학습은 기존대로 마지막으로 본 단어 한 개를 여는 기능이다. 학습 목록 전체의 순서를 저장하는 기능은 이번 범위에 포함하지 않았다.

외래어 조합은 일본 문화청의 [외래어 표기 제1·제2표](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/gairai/honbun01.html)를 대조했다. 이는 표기의 대응 자료이며 한글 발음은 자체 근사 표기다. 모든 외국어 발음과 특수 표기를 망라하지는 않는다. 화면의 참고 링크를 제거해도 근거는 소스·문서에 남긴다.

## 검수 상태와 미완료 항목

이번 변경은 화면과 탐색에 한정되며 콘텐츠 DB는 1.0.5 이후와 동일하다. SHA-256: `be94baa977fdd415a20fd96898b3754988997e4ca2ac2c3b9320995dc845047b`.

검수 화면을 앱에서 제거한 것이 검수 완료 상태로 승격했다는 뜻은 아니다. 사람 검수는 뜻·훈음·예문 각각 0개이며 기존 상태는 draft다. 예문 전체 AI 검토와 독립된 사람 검수는 구분한다. 원문 확인 94개 문장쌍(97개 ID) 등 남은 검수 항목은 [전체 예문 검토 보고서](FULL_EXAMPLE_REVIEW.md), DB 및 CSV 이력에 그대로 보관한다. 기존 strict 출시 게이트 차단 상태도 유지한다.
