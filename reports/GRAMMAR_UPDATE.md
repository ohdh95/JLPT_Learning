검증일: 2026-10-28 (Asia/Seoul). Flutter 3.47.8 / Dart 3.13.7 / JDK 17 / Android API 36 x86_64 에뮬레이터.

## 구현

- 단어 학습·테스트 카드의 JMdict 코드 대신 학습용 품사 이름 표시. 명사, 1단동사, 5단동사, 불규칙동사, い형용사, な형용사, 부사, 연체사, 접속사, 조사, 감동사, 조동사. 복수 품사 보존.
- 카드의 품사 행을 누르면 자동사·타동사, 접사·관용표현 등 보조 태그 표시. 사전의 `vs` 명사와 실제 する동사, 보조동사/보조형용사와 조동사 구별.
- 단어/별표 목록에 품사 필터 추가. 기존 필터와 함께 작동하고 페이지를 첫 페이지로 조정하며 선택 ID 집합은 보존.
- 기록 탭을 문법 탭으로 교체. 5개 활용 자료를 오프라인으로 제공. 기본 활용은 펼침, 추가 활용표는 접힘. 문법 열람으로 사용자 DB에 기록을 쓰지 않음.
- 1단·5단·する·来る의 기본/정중/부정/과거/て형과 가능·수동·사역·조건·의지·명령·금지, い·な형용사의 기본/정중/부정/과거/연결/조건/수식 형태. 5단 어미별 て/た 규칙과 대표 예외 포함.
- 훈음은 `会 · 모일 회`처럼 표시. 훈만/음만 숨김과 준비 중·미검수 상태 유지.
- 콘텐츠 DB·사용자 DB 스키마는 변경하지 않음. 테스트 이어하기·결과·재시험·백업 데이터 유지.

## 범위와 남은 검수

- 원본 품사 정보가 없는 **11개 단어**는 ‘품사 정보 확인 중’으로 남긴다. 12개 주 분류에 맞지 않는 접사·관용표현·문어 표현 등은 원본에 따른 보조 태그를 표시한다. 단어별 품사·의미 문맥의 사람 검수가 완료되었다고 주장하지 않는다.
- 문법은 대표형의 참고 학습 자료다. 모든 단어의 특수 활용을 자동 생성하거나 문법 시험/진도 기록을 만드는 기능은 포함하지 않는다. 참고 자료 주소는 앱의 각 문법 상세와 README에 있다.
- 한국어 뜻·한자 훈음·예문 번역의 사람 검수 완료는 여전히 각각 0개다. 기존 뜻 17개·훈음 15개는 초안 상태 그대로다. DB 자산 SHA-256은 d8dddd3f327b957d69f1cb1c71730748858c9e0af7b1029ab39b5f16ac5be0a5.
- 실물 ARM64 휴대폰 및 iOS 실행은 이번에 확인하지 않았다. 이번 Android 확인은 일반 APK 설치와 화면 조작이며, 초기 버전의 instrumentation 통합 검사를 새로 실행한 것은 아니다.
