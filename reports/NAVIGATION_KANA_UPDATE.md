# 메뉴·가나·한자 학습 변경 · 1.0.6+7

2026-10-28 · Ubuntu 22.04 / Flutter 3.47.8 / Dart 3.13.7 / JDK 17 / Android API 36.

## 완료한 기능

- 하단 메뉴는 **단어 · 한자 · 가나 · 별표 · 문법**이다. 첫 화면 이름을 홈에서 단어로 바꾸고 급수를 누르면 단어장을 연다. 기존 한자 탭의 검색·급수 선택·신규/누적 목록을 유지한다.
- 가나 표는 기본 46개, 탁음·반탁음 25개, 요음 36개를 히라가나/가타카나/한글 발음 순서로 표시한다. 한글은 근사한 참고 발음이며 조사 は·へ·を, ん, 촉음·장음과 드문 요음을 안내한다. 인터넷이 필요 없다.
- 단어의 밑줄 친 한자 풀이를 누르면 전체 한자 상세로 이동한다. 학습·테스트 카드에서 모두 사용할 수 있고 돌아오면 카드 위치와 임시 정답 표시를 유지한다. 테스트 앞면에서 한자 상세를 여는 동작이 카드를 뒤집거나 평가를 저장하지 않는다.
- 한자 상세의 관련 단어는 기본 접힘이다. 펼칠 때 목록을 조회하며 관련 단어 학습으로 이동할 수 있다. 새로 상세를 열면 다시 접혀 있다. 급수가 없는 보충 한자는 급수 미지정, 일본어 읽기가 없으면 읽기 정보 없음으로 표시한다.
- 새 학습 표시 설정의 기본값은 표제어만 보이는 암기 방식이다. 일반/암기 모드 버튼을 제거했으며 개별 토글, 모두 숨기기/표시하기, 임시 정답 보기/정답 닫기는 유지한다. 기존에 저장한 표시 설정은 덮어쓰지 않는다.
- 품사 옆 정보 아이콘을 **자세히 ›**로 바꿨다. 자동사·타동사 등 기존 보조 설명을 연다.

실제 320×640 에뮬레이터에서 다섯 메뉴, 기존 한자 목록, 一 한자 상세의 관련 단어 기본 접힘/펼침, 가나 기본/탁음·반탁음/요음 표를 확인했다. 화면과 UI 트리는 `navigation-screens/`에 보관한다.

실제 SQLite를 사용하는 테스트로 다섯 탭 이동, 한자 탭 검색·상세, 급수 목록 진입, 선택·별표 보존, 한자 관련 단어 왕복, 임시 정답/표시 설정 보존, 테스트 앞면의 평가 방지, 보충 한자, 가나 표 320px 및 글자 배율 1/1.5/2를 검사했다. 기존 320×640 학습 카드와 예문/해석 접힘 테스트도 통과했다.

개발 중 추출한 한자 화면의 import 누락, 테스트의 스크롤 반영 대기 및 검색 급수에 맞지 않는 테스트 입력을 수정했다. 최종 실행 결과는 위 로그에 기록했다. 이전 Android instrumentation 테스트는 사용자 선택 데이터를 초기화하므로 이번 업데이트에서 재실행하지 않았다. 현재 기기의 사용자 DB를 별도로 백업하고 갱신 설치 전후를 직접 비교했다.

## 가나 자료와 범위

문자 대응은 국제교류기금 [MARUGOTO 히라가나](https://a1.marugotoweb.jp/en/hiragana.php), [가타카나](https://a1.marugotoweb.jp/en/katakana.php), [이로도리 가나 자료](https://www.irodori.jpf.go.jp/assets/data/Kana_all.pdf)를 대조했다. 한글 발음은 한국인 학습자를 위한 자체 참고 표기로 정확한 음성기호나 공식 외래어 표기가 아니다. 외래어용 확장 조합(ファ・ティ 등), 가나 퀴즈와 가나 음성 버튼은 이번 범위에 포함하지 않는다.

콘텐츠 DB는 이전 1.0.5와 동일하다. SHA-256: `be94baa977fdd415a20fd96898b3754988997e4ca2ac2c3b9320995dc845047b`. 뜻·훈음·예문의 사람 검수 상태를 올리지 않았다. strict 출시 게이트는 종료 코드 2로 계속 차단하며 독립된 사람 검수와 원문 이슈 해결은 [전체 예문 검토 보고서](FULL_EXAMPLE_REVIEW.md)의 미완료 항목으로 남는다.

실물 ARM64 휴대폰·iOS 실행은 이번 환경에서 확인하지 않았다. API 36 x86_64 에뮬레이터에서 범용 APK를 사용했다. 두 APK는 개발용 디버그 서명이며 스토어 배포용 서명은 하지 않았다.
