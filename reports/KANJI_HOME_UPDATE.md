# 한자 급수 선택·진도·이어서 학습 · 1.0.12+13

2026-10-28 (Asia/Seoul)

## 완료한 기능

- 한자 탭을 열면 단어 탭처럼 N5~N1 급수 선택, 각 급수의 학습 완료 수/전체 수와 진도 막대를 표시한다.
- 급수를 선택하면 해당 급수 한자 목록을 연다. 검색·페이지 크기·여러 페이지 선택·학습 표시 해제·선택한 한자 테스트는 유지한다.
- 한자의 **이어서 학습**은 N5→N1, 각 급수 안에서는 기존 한자 목록 순서의 첫 미학습 한자를 연다. 일반 상세와 동일하게 이전·다음으로 이동하고 처음에는 정답을 숨긴다.
- 한자 학습 완료 기준은 상세의 정답 보기를 누른 시점이다. 상세를 여는 것만으로 완료시키지 않는다. 정답 확인 또는 표시 해제 후 첫 화면의 진도와 다음 이어서 학습 대상이 갱신된다.
- 급수 한자 2,383자를 모두 완료하면 전체 학습 완료로 버튼을 비활성화한다. 급수 미지정 보충 한자는 급수별 진도와 이어서 학습에서 제외한다. 단어 학습 표시와 한자 학습 표시는 독립적이다.
- 앱 이름 **일본어 완전정복**, 부제 **가나부터 JLPT N1까지**, 벚꽃색 **あ** 아이콘을 유지한다.
