# 학습 완료 표시·전체 순서 탐색·한자 테스트 · 1.0.9+10

2026-10-28 · Flutter 3.47.8 / Dart 3.13.7. 이전 중간 보고서보다 이 문서를 우선한다.

## 완료한 동작

- **단어 학습 완료 기준은 학습 화면의 ‘정답 보기’를 누른 시점이다.** 상세를 열거나 이전/다음으로 이동하는 것만으로는 완료되지 않는다. 정답을 닫아도 완료 표시는 유지한다. 학습 정보 표시 설정을 제거하고 처음에는 단어 표기(한자·가나)만 보이도록 고정했다. 구형 표시 설정은 화면에 적용하지 않는다.
- 한자도 상세의 정답 보기를 누르면 학습 완료로 표시한다. 처음에는 한자만 보이며 훈음·음독·훈독·급수·관련 단어는 숨긴다. 정답 숨기기로 가려도 완료는 유지하고 다음 한자로 이동하면 정답은 다시 숨긴다. 학습한 단어/한자는 목록에서 칸 전체를 회색 배경으로 표시하고, 단어 첫 화면의 진도는 완료 단어 수로 계산한다.
- 완료 표시가 있는 상세의 체크 버튼으로 개별 해제한다. 목록의 전체 선택과 학습 표시 해제로 전체 표시도 지울 수 있으므로 설정의 별도 전체 초기화를 제거했다. 별표·선택·기존 시험 기록은 보존하며 다시 정답 보기를 누르면 완료된다.
- 단어·한자 체크박스로 고른 뒤 **학습 표시 해제**를 누르면 선택한 완료 표시만 일괄 해제한다. 회색 배경을 없애되 체크 선택·별표는 보존한다. 글자 굵기는 기본값이다. 원본/읽기 정렬 선택 칸을 제거하고 원본 순서를 고정한다.
- **이어서 학습은 N5→N4→N3→N2→N1의 원본 순서에서 첫 미완료 단어를 연다.** 마지막 방문 위치로 이동하지 않는다. 완료한 단어를 건너뛰고 중간 표시를 해제하면 그 항목을 다시 찾는다. 전체 7,811개를 완료하면 버튼을 전체 학습 완료로 비활성화한다.
- 단어 상세의 이전/다음은 목록 페이지·검색·품사·별표·선택과 무관하게 전체 원본 순서를 따른다. 한자 상세도 N5→N1, 급수 안에서는 문자 순서로 전체 2,383자를 이동한다. 모든 급수 경계에서 양방향 이동하며 전체 첫/끝에서만 해당 방향 버튼을 끈다. 급수 미지정 보충 한자는 단독 상세로 표시한다.
- **단계 전체 선택**은 검색/품사/별표/페이지와 무관하게 선택 급수 전체를 선택하고 기존 선택을 보존한다. 모든 급수에서는 **전체 급수 선택**으로 7,811개를 선택한다. 현재 페이지 선택은 별도로 유지한다.
- 한자 목록을 단어와 같은 체크박스 행 목록으로 바꿨다. 페이지 크기·페이지 이동·현재 페이지 선택·단계 전체 선택·선택 목록·선택 해제를 제공한다. 한자 선택은 단어 선택과 별도로 저장하며 페이지·검색·급수·재시작을 넘어 유지한다. **한자 테스트**는 체크한 한자만 중복 없이 섞어 출제한다.
- 단어·한자 시험은 **문제만 보이는 앞면 → 정답 확인 → 다음 문제 → 완료 → 전체 재시험**이다. 앞뒷면 정보 설정, 모름/애매함/알고 있음, 평가 수정, 평가별 재시험과 비율을 제거했다. 단어 뒷면의 예문·해석은 기존 요청에 따라 각각 기본 접힘을 유지한다.
- **상태 필터, 평가 배지, 이어서 테스트, 기록 화면을 제거했다.** 기존 시험 데이터는 보존한다. 새 시험은 정답 확인 후 다음으로 진행한 사실만 `seen`으로 저장하며 학습 완료나 암기 정도를 추정하지 않는다. 시험 진행과 학습 화면의 정답 보기 완료 표시는 독립적이다.
- 하단은 단어·한자·가나·별표·문법을 유지한다. 한자 칸의 급수 표기와 신규/누적 선택은 제거하고 선택 급수만 표시한다. 한자 관련 단어·예문·해석의 기본 접힘을 유지한다.
- 가나 표의 외래어 33개(ファ·ティ·ヴァ 등), 단어에서 한자 상세 이동, 예문에서 단어 상세 이동, 학습용 품사·활용 문법, 별표·다중 선택·TTS는 유지한다. 데이터 안내·참고 자료·검수 현황 화면을 제거하되 라이선스 고지와 근거는 보존한다.

외래어 표기는 일본 문화청 [외래어 표기 제1·제2표](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/gairai/honbun01.html)를 대조했다. 한글 발음은 자체 근사 표기다.

## 사용자 데이터 보존

- 콘텐츠 DB와 사용자 DB를 분리한다. user.db 스키마 1/2→3 마이그레이션은 설정·선택·별표·시험 스냅샷·응답을 유지하면서 학습 표시와 시험 종류를 추가한다. 기존 응답의 평가 값은 그대로 보존한다.
- 단어·한자의 정답 보기는 `learning_visits`에 종류와 ID, 시각을 저장한다. 한자 선택은 `kanji_selection`에 문자를 저장한다. 구형 `last_study`나 자기 평가에서 정답 보기 완료를 추정하지 않는다. 구버전의 확인되지 않은 학습 표시는 새로 만들지 않는다.
- 새 백업 형식은 `jlpt-user-v3`이며 학습 표시·한자 선택·한자 시험을 포함한다. `jlpt-user-v1`/`jlpt-user-v2` 복원도 지원한다. 손상된 백업을 검증한 후 트랜잭션으로 교체한다.
- `learning_progress_test.dart`는 실제 v1 스키마를 생성하고 v3로 열어 설정·선택·별표·평가 보존, 새로운 무평가 진행, 구형 백업 복원을 검사한다.

## 데이터 검수와 남은 작업

이번 변경은 앱 동작과 사용자 DB에 한정한다. 콘텐츠 SHA-256은 `be94baa977fdd415a20fd96898b3754988997e4ca2ac2c3b9320995dc845047b`로 유지된다. 단어 뜻 7,811개, 한자 훈음 2,542자, 예문 번역 13,718개가 채워져 있다.

## 1.0.9 빌드와 에뮬레이터 확인

- 범용 및 ABI 분리 디버그 빌드 성공. 범용에는 armeabi-v7a·arm64-v8a·x86_64, ARM64 파일에는 arm64-v8a만 포함한다. 두 APK 모두 Android 서명 검증을 통과했다.
- 실제 Android 버전 이름은 모두 1.0.9다. versionCode는 범용 10, ARM64 분리본 2010이다(Flutter ABI별 버전 코드 가산). 근거: `learning-flow-apk-metadata.json`, `learning-flow-*-signature.log`, 빌드 로그.
- 사용 중인 API 36 x86_64 에뮬레이터에 범용 APK를 `adb install -r`로 업데이트하고 초기 화면이 열린 뒤 확인했다. user.db 스키마 2→3 마이그레이션과 무결성/외래키 검사를 통과했다.
- 설치 직전 새 백업을 보존했다. 설정 4행, 선택 0행, 별표 0행, 시험 2행, 응답 1행, 학습 표시 4행을 설치 전후 모든 열 값으로 비교해 동일함을 확인했다. 새 한자 선택 테이블은 빈 상태다. 근거: `learning-flow-install.json`. 이전 v1→v2 설치 증거는 `learning-flow-v1-migration.json`에 구분해 보존한다.
- 에뮬레이터 단어 목록의 완료한 행 전체가 회색인 것을 화면 캡처로 확인했다. 학습 표시나 체크 선택을 변경하는 조작은 하지 않았다. 최신 화면 근거는 `learning-flow-final-screens/`에 보관한다.
- Gradle의 기존 Kotlin 플러그인 이관 경고는 남아 있지만 이번 디버그 빌드는 성공했다. 정식 배포 서명 및 iOS 빌드·실물 기기 검증은 이번 작업에서 하지 않았다.
