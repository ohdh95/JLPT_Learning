# 단어 학습 화면 개선 · 1.0.1+2

검증일: 2026-10-28 (Asia/Seoul).

## 반영한 동작

- 단어 학습 카드 및 학습 표시 설정에서 급수 제거. 급수 데이터와 단어장 필터는 유지.
- 예문·후리가나·번역을 기본 접힘으로 변경. 필요한 경우 펼치고 예문 발음을 재생할 수 있음.
- 다른 단어로 이동하면 예문은 다시 접히고 스크롤 위치는 맨 위로 초기화.
- 학습 표시 설정 및 일반/암기 프리셋은 상단 조절 버튼으로 이동.
- 한자 훈·음은 한 행으로 묶고 반복된 미검수 안내를 공통 안내로 줄임. 검증되지 않은 정보를 검수 완료로 바꾸지 않음.
- 이전·정답 보기·다음 버튼을 하단에 고정. 일시 정답 공개는 저장된 표시 설정을 변경하지 않음.
