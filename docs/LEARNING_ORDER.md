# 단어 기본 학습 순서

2026-11-01 요청을 반영한 1.0.16의 기본값이다. 정렬 선택 칸은 추가하지 않는다.

| 급수 | 먼저 | 다음 | 마지막 |
| --- | --- | --- | --- |
| N5 | 자주 쓰는 기초 단어 | 일상생활 명사·동사·형용사 | 나머지 |
| N4 | N5에서 배운 단어와 연관된 표현 | 자주 쓰는 동사·복합 표현 | 나머지 |
| N3 | 일상 및 사회생활에서 자주 쓰는 단어 | 추상적인 표현 | 나머지 |
| N2 | 사용 빈도가 높은 한자어·복합어 | 유의어·다의어 | 나머지 |
| N1 | 자주 등장하는 고급 어휘 | 추상적인 한자어·관용 표현 | 드물고 어려운 표현 |

단어 목록, 검색·품사·급수·별표·선택 필터, 한자 상세의 관련 단어, 단어 상세 이전/다음, 이어서 학습에서 같은 순서를 쓴다. 전체 급수 순서는 N5→N4→N3→N2→N1이다. 무작위 테스트는 계속 무작위로 출제하고 한자 순서는 바꾸지 않는다.

## 분류와 정렬 근거

학습 단계는 `pipeline/data/learning_order_policy.json`의 편집 목록과 `pipeline/build_learning_order.py`의 규칙을 결합한다. 먼저 해당하는 단계에 넣고 단계 안에서는 빈도 추정치 내림차순, 동률이면 원본 순서·ID로 고정한다. 원본 `source_index`를 덮어쓰지 않는다.

- N5: 기본 표현 편집 목록 → 빈도 3.5 이상 명사·동사·형용사 → 나머지.
- N4: 편집자가 연결한 실제 N5 단어 ID가 있는 표현 → 빈도 3.5 이상 동사·한자 복합어·표현 → 나머지. 연관성은 글자가 같다는 이유로 추정하지 않는다. 예: 乗り換える는 乗る·電車에 연결된다. 이는 고정 교육과정이며 사용자별 N5 완료 상태에 따라 목록이 재배열되는 기능은 아니다.
- N3: 일상·사회생활 편집 목록 또는 빈도 4.0 이상 내용어 → 추상 표현 편집 목록·뜻의 단서 → 나머지.
- N2: 빈도 4.0 이상 한자 복합어 → 유의어 편집 목록 또는 빈도 3.3 이상 JMdict 복수 의미 항목 → 나머지.
- N1: 빈도 4.0 이상 내용어 → 빈도 2.5 이상 추상 표현 또는 관용 표현 → 나머지.
- N3·N1의 빈도 우선 판정에서는 한 글자 표기, 순수 접사, 하위 급수에 같은 표기가 있는 항목을 제외한다. 예를 들어 奴의 전체 표기 빈도를 N1의 やっこ 읽기 빈도로 취급하지 않는다.
- JMdict의 해당 표기·읽기에 허용되는 의미가 모두 희귀·고어·역사어로 표시된 경우 뒤로 보낸다. JMdict 의미 수는 한국어 뜻 개수를 세어서 추정하지 않는다.

빈도는 **wordfreq 3.1.1의 일본어 표기별 빈도**를 사용한다. 약 2021년까지 여러 말뭉치를 합친 자료로, JLPT 출제 빈도나 특정 읽기·뜻의 빈도가 아니다. 원문에 없는 복합 표현의 빈도를 개별 단어 빈도로 합성하지 않는다. 직접 일치하는 표기는 7,478/7,811개다. 누락된 빈도는 0으로 기록하되 희귀어로 검증됐다는 뜻은 아니다. 마지막 단계에는 자료가 없거나 앞 단계의 근거가 부족한 항목도 들어간다.

단계·유의어·추상 표현 분류는 편집 및 자동 규칙 기반 추천이며, 학습 효과나 모든 분류의 정확성을 검증한 공식 교육과정이 아니다. 기존 뜻·훈음·예문의 검수 상태는 변경하지 않는다. 상세 근거는 DB `word_learning_order`와 `source_info.learning_order`에 보존한다.

## 재생성

표제어·급수·ID와 빈도·사전 근거 스냅샷은 `pipeline/data/learning_order_evidence.json`에 저장한다. Python 표준 라이브러리만으로 오프라인 재적용할 수 있다.

```bash
python pipeline/build_learning_order.py --db assets/content.sqlite
```

기본 DB 생성기 `pipeline/build_database.py`도 이 순서를 설치한다. 스냅샷에 없는 새 항목·fixture는 해당 급수의 마지막에 원본 순서로 둔다. 같은 ID의 표기·읽기·급수가 달라졌다면 오래된 근거로 조용히 정렬하지 않고 오류를 낸다.

빈도·JMdict 근거 자체를 새로 추출할 때만 별도 Python 환경에 `wordfreq==3.1.1`을 설치하고 다음 명령을 사용한다.

```bash
python pipeline/build_learning_order.py --db assets/content.sqlite --refresh-evidence --jmdict downloads/JMdict_e.gz
```

JMdict 정보는 기존 직접 대조가 성공한 ID의 해당 의미에만 사용한다. 재생성은 사용자 DB를 열지 않으며 단어·한자·예문·번역·학습 기록을 수정하지 않는다. 앱은 새 콘텐츠 DB와 기존 사용자 DB를 연결하므로 별표·선택·학습 완료는 안정적인 ID를 따라 유지된다. 구형 콘텐츠에 순서 테이블이 없을 때는 원본 순서로 열 수 있다.
