# 일본어 완전정복 — 통합 기능 명세 v1.4

> 1.0.10+11: 앱 이름은 **일본어 완전정복**, 부제는 **가나부터 JLPT N1까지**다. 첫 화면에 표시하고 하단 메뉴 이름은 유지한다.

> 2026-10-28 사용자 변경 요청 반영: 단어 학습 카드에서 급수를 제거한다. 예문·후리가나·번역은 기본 접힘이며 단어 이동 시 다시 접는다. 학습 정보 표시 설정은 제거하고, 이전·정답 보기·다음은 하단 고정한다. 급수 데이터와 급수별 필터는 유지한다.

> 1.0.9+10 사용자 최종 변경: 하단은 **단어 · 한자 · 가나 · 별표 · 문법**이다. 단어 첫 화면에는 급수 선택과 정답 보기 기준 진도, **N5→N1 순서에서 첫 미학습 단어를 여는 이어서 학습**만 제공한다. 마지막 방문 위치를 여는 기능과 이어서 테스트는 제공하지 않는다. 단어·한자 상세 이동은 전체 급수 순서로 이어지고 목록/검색/페이지에 제한되지 않는다. 단어는 정답 보기, 한자는 정답 보기 시 완료로 표시하고 목록의 칸 전체를 회색 배경으로 표시하며 개별/체크 선택한 항목의 학습 표시 해제를 지원한다. 별도 설정의 전체 초기화는 제공하지 않는다. 상태 필터와 테스트 자기 평가·앞뒷면 설정을 없애고 한자 테스트를 추가한다. 테스트 앞면은 문제만, 뒷면은 모든 정답 정보를 표시하며 예문과 해석은 접힘을 유지한다. 한자 탭은 선택 급수만, 칸에는 한자·훈음만 표시한다. 관련 단어는 기본 접힘이며 이동 시 접힘/스크롤을 초기화한다. 가나에 외래어 가타카나 33개를 추가한다. 데이터 안내·참고 자료·검수 현황 화면을 제거하되 검수 근거와 라이선스 고지는 보존한다. 학습은 표제어만 표시하는 암기 방식으로 고정하며 구형 표시 설정을 무시한다. 이 변경은 아래 원본보다 우선한다.

**대상:** 히라가나/가타카나를 익힌 한국어 사용자. **범위:** JLPT N5~N1 학습용 한자·어휘. **형태:** 모바일 앱. **테스트:** 무작위 카드 뒤집기 + 다음 문제.

> JLPT 급수별 공식 고정 어휘/한자 목록은 공개되지 않으므로 모든 급수 구분은 출처가 표시된 학습용 비공식 분류로 표시한다.

> 1.0.12+13: 한자 탭 첫 화면도 N5~N1 급수 선택, 급수별 완료 수/전체 수, 진도 막대, 이어서 학습으로 구성한다. 급수를 선택하면 해당 한자 목록을 열며 이어서 학습은 N5→N1 순서의 첫 미학습 한자를 연다. 한자 학습 완료는 정답 보기 기준이며 보충 한자는 급수 진도에서 제외한다. 전체 완료 시 이어서 학습을 비활성화한다.

## 2. 단어 정보

- 일본어 표기(항상 표시), 가나 읽기, 한국어 뜻(다의어 가능), 품사, JLPT 학습 급수
- 단어를 구성하는 한자 각각의 한국식 훈과 음, 해당 단어에서 사용되는 일본어 읽기
- 일본어 예문과 한국어 번역, 발음 재생(TTS)
- 한자별 읽기를 분해하기 어려운 `明日（あした）` 같은 단어는 전체 읽기만 표시하고 글자별 발음을 임의 생성하지 않는다.
- 한자 없이 가나만 있는 단어는 한자 풀이를 숨긴다.

## 3. 한자 정보

- 선택한 급수의 한자만 표시하며 신규/누적 전환은 제공하지 않는다
- 한자별 한국식 훈음, 음독·훈독, 관련 단어 표시
- 한자별 상세에서 관련 단어 선택 시 단어 상세로 이동
- 한자와 단어는 독립된 급수 분류를 가지며 각 급수를 강제로 동일시하지 않는다.

## 4. 페이지 크기 및 다중 선택

- 사용자가 페이지당 단어 수를 10/20/30/50/100개 또는 직접 입력(1~200개)으로 설정, 기본값 20개
- 이전/다음 페이지, 현재 범위/전체 단어 수, 전체 페이지 수, 특정 페이지 바로 이동
- 각 페이지에 **현재 페이지 전체 선택 / 현재 페이지 전체 선택 해제** 제공
- 일부 선택일 때 체크박스에 부분 선택 상태 표시
- 다른 페이지·검색 결과·급수·별표 목록으로 이동해도 선택 목록 유지
- 총 선택 개수를 하단에 고정 표시하고, 선택 목록에서 개별 해제·선택 해제 제공
- 선택 목록은 고유 단어 ID 집합으로 관리. 페이지 크기 변경에도 유지
- **단계 전체 선택**은 검색/품사/별표/페이지와 관계없이 선택 급수 전체를 선택한다. 모든 급수에서는 전체 급수 선택을 제공하며 기존 선택을 보존한다
- 검색/필터가 바뀌면 페이지 번호를 재계산하되 기존 선택은 유지
- 테스트에 포함되는 동일한 단어는 한 번만 출제

## 5. 고정된 학습·테스트 표시

- 학습 정보 표시 설정과 모두 숨기기/모두 표시하기 설정 버튼은 제공하지 않는다.
- 단어 학습은 일본어 표제어(한자·가나)만, 한자 상세는 한자 한 글자만 처음에 표시한다.
- **정답 보기**로 읽기·한국어 뜻·품사·한자 훈음 등 정답 정보를 연다. 단어의 정답 닫기와 한자의 정답 숨기기로 다시 가릴 수 있다.
- 예문과 해석, 한자 관련 단어는 각각 기본 접힘이다. 단어 학습 카드에는 급수를 표시하지 않는다.
- 이전/다음으로 이동하면 다시 정답을 숨긴다. 정답을 숨겨도 완료 표시는 유지한다.
- 테스트 앞면은 일본어 단어/한자 문제만, 뒷면은 모든 정답 정보를 표시한다. 예문과 해석은 별도로 펼친다.
- 구형 학습·테스트 표시 설정은 백업 호환을 위해 보존할 수 있지만 현재 화면에는 적용하지 않는다.

## 6. 별표 및 취약 단어

- 목록·상세·테스트·결과 화면에서 별표 추가/해제
- 별표 목록도 일반 단어 목록과 동일한 페이지 크기 지정·검색·다중 선택 지원
- 별표는 사용자 지정 표식이므로 '모름' 평가만으로 자동 별표 처리하지 않음
- 별표 변경은 테스트 이력을 변경하지 않음

## 7. 카드 뒤집기 테스트와 학습 표시

1. 여러 페이지에서 선택한 단어를 무작위로 출제한다. 한자도 체크박스로 고른 항목만 무작위 출제한다. 단어와 같은 행 목록·페이지 크기·페이지 이동·현재 페이지/단계 전체 선택을 제공하며 한자 선택은 단어 선택과 별도로 저장한다.
2. 중복을 제거하고 앞면은 문제만 표시한다. 카드/정답 확인 버튼으로 뒤집으면 정답 정보를 표시한다.
3. 뒤집은 현재 카드에서만 다음 문제로 진행한다. 중복 누름은 한 번만 반영한다.
4. 마지막 문제 뒤 확인한 개수와 전체 재시험 버튼을 표시한다. 재시험은 새롭게 셔플한다.
5. 자기 평가·점수·평가별 목록·상태 필터·이어서 테스트는 제공하지 않는다. 구형 시험 데이터는 삭제하지 않는다.
6. 단어는 학습 화면의 정답 보기를 누르면 완료로 저장하며 열기/이전·다음만으로 완료되지 않는다. 한자도 정답 보기를 누르면 학습 표시를 저장한다. 완료한 항목은 목록의 칸 전체를 회색 배경으로 표시한다. 상단 체크 버튼으로 개별 해제하고 목록에서 선택한 항목의 학습 표시 해제로 일괄 해제한다. 별도 전체 초기화 설정은 제공하지 않는다. 시험 진행만으로 상세 방문을 추정하지 않는다.
7. 이어서 학습은 N5부터 N1까지 전체 원본 순서에서 첫 미학습 단어를 연다. 모두 학습했다면 완료로 비활성화하며, 중간 표시를 지우면 그 항목이 다시 대상이 된다.
8. 단어·한자 목록의 체크박스는 테스트 대상 선택에 사용한다. 선택한 항목의 학습 표시 해제로 여러 완료 항목을 한 번에 미학습으로 바꿀 수 있다. 선택과 별표는 유지한다. 정렬 선택 칸은 없고 원본 순서로 고정한다. 한자 상세는 기본적으로 한자만 표시하며 정답 보기/정답 숨기기를 제공한다.
9. 상세의 이전/다음은 목록 필터나 페이지에 제한되지 않으며 전체 처음/끝에서만 비활성화된다. 보충 한자에 급수를 새로 부여하지 않는다.

## 8. 앱 데이터베이스

**사전·학습 콘텐츠**

- `words`: 단어 표기, 가나 읽기, 뜻, 품사, 급수, 사전 ID, 출처, 검수 상태
- `kanji`: 한자, 한국식 훈/음, 일본어 음독/훈독, 급수, 검수 상태
- `word_kanji`: 구성 한자, 위치, 실제 사용 읽기/특수 읽기 표시
- `examples`: 일본어 문장, 한국어 번역, 읽기, 예문 출처/번역 검수 상태
- `data_sources`: 원본 자료의 URL, 라이선스, 저작자/사용 조건
- `dictionary_checks`: 어떤 사전과 언제 어떤 항목을 확인했는지 증거
- `review_queue`: 미검수·불일치 항목과 해소 이력

**사용자 데이터**

- `user_word_state`: 별표
- `learning_visits`: 단어/한자 종류, 안정적인 항목 ID, 학습 표시 시각(단어 정답 보기/한자 정답 보기)
- `selection`: 페이지와 독립된 테스트용 단어 선택 집합
- `kanji_selection`: 페이지와 독립된 테스트용 한자 선택 집합
- `user_preferences`: 페이지 크기, 테마와 호환을 위한 구형 설정
- `test_sessions` / `test_responses`: 종류, 출제 순서, 진행 위치, 정답 확인 후 진행 기록(seen)과 보존된 구형 평가

## 9. 데이터 구축 및 더블체크 (v1.4 신규 필수 절차)

**단계 A — 라이선스 및 자료 원천 확인**

- 네이버 N5-1 등의 원본 단어 목록을 이용할 때 자동 수집 및 재사용 허가 여부를 먼저 확인한다.
- 허가되지 않은 대량 복제나 접근 차단 우회는 하지 않는다.
- 네이버 원본을 수집할 수 없으면, 출처/라이선스가 확인된 OpenJLPT 등 대체 목록을 사용한다.
- 모든 입력 데이터에 출처 URL, 수집일, 버전, 라이선스를 기록한다.

**단계 B — 추출·정규화·중복 제거**

- 단어 표기·가나 읽기·급수·원본 순서를 추출하고 원본 자료를 보존한다.
- Unicode·가나 표기·공백·이체자 정규화를 별도 단계에서 수행한다.
- 표기+읽기+사전 의미를 기준으로 동음이의어를 무리하게 합치지 않는다.

**단계 C — 정보 자동 보강**

- 일본어 가나·뜻 후보·품사·한자 음훈독과 한국어 훈음 후보·예문을 연결한다.
- 한국어 뜻이나 예문 번역을 새로 작성하면 **초안**임을 표시한다.
- 읽기 분해 불가·다의어·타동사/자동사 구별 등은 별도 검토 대상으로 기록한다.

**단계 D — 사전 더블체크**

- 일본어 표기+읽기: 원본 목록 → JMdict 원본 파일에 재조회
- 뜻·품사: JMdict와 별도 일본어 사전/용례로 확인. 대표 뜻과 추가 뜻 구분
- 한국어 뜻: 독립적인 허가된 한국어 사전 자료와 의미·문맥 대조
- 한자: KANJIDIC2의 일본어 읽기와 한국 한자 사전의 훈/음 각각 검증
- 예문: 문법·자연스러움·한국어 번역 검수
- 급수: 자료간 이견이 있으면 임의로 맞추지 않고 출처별 급수 차이를 기록

> OpenJLPT는 이미 JMdict와 연결돼 있으므로 OpenJLPT의 JMdict ID 확인만으로 '완전히 독립된 두 사전 검수'라고 간주하지 않는다. 실제 JMdict 원본 재조회와 애매한 단어의 별도 사전 확인이 필요하다.

**단계 E — 검증 리포트 및 출시 게이트**

- 단어별 `표기/읽기 확인`, `품사 검수`, `한국어 의미 검수`, `한자 훈음 검수`, `예문 검수`, `급수 일치/불일치` 상태 저장
- 불일치/미확인 항목은 내부 CSV와 보고서에 기록하며 앱 검수 화면은 제공하지 않는다
- 모든 필수 항목의 검수가 완료된 단어만 배포용 콘텐츠로 확정
- 원시 자료와 확정 자료를 분리하고 수정 이력을 보존

**단계 F — 데이터 업데이트**

- 원본 변경/오류 신고 시 항목만 재검수하고 DB 버전 올리기
- 앱 업데이트 시 사용자 별표·테스트 기록·선택 상태 유지
- 사용 중인 라이선스의 출처 표시와 동일조건공유 의무 준수

## 10. 검증 시나리오

- 페이지당 1~200개 변경/현재 페이지 전체 선택/페이지 간 누적 선택이 정상 동작
- 급수·검색·필터 이동 후 선택 유지 및 중복 없이 테스트
- 학습·테스트 표시 설정 제거 및 고정된 앞면 숨김/뒷면 표시, 오래된 설정에 영향받지 않음
- 다음 단어로 넘어가면 임시 정답 공개 상태 복원
- 단어/한자 테스트의 중복 방지·원자적 진행·재시험, 구형 사용자 DB 보존
- 정답 보기 완료 표시의 개별/체크 선택 일괄 해제, 재시작·백업 복원, 모든 급수 경계 및 첫 미학습 탐색
- 별표와 테스트 기록 분리
- `明日` 등 특수 읽기의 한자별 억지 분해 방지
- 사용권/출처 미확인 또는 한국어 뜻 미검수 자료의 배포용 확정 차단
- DB 관계·중복·빈 값·자료 출처·사전 대조 로그의 정합성 점검

## 11. 첨부 원본 v1.4 시제품의 기록 (현재 앱과 구분)

현재 앱은 단어 7,811개·급수 한자 2,383개와 보충 159개·예문 13,718개를 포함한다. 아래는 첨부 당시 작은 시제품의 설명이며 현재 데이터 건수가 아니다. 최신 결과는 README와 reports/LEARNING_FLOW_UPDATE.md를 따른다.

제공된 SQLite 시제품은 **20개 단어, 15개 한자, 20개 독자 작성 예문**과 일본어 사전 검증 로그로 구성한다. 네이버 사전에서 N5~N1 전체를 직접 추출한 결과가 아니다.

- 20개 중 16개는 OpenJLPT N5 자료와 표기·읽기가 일치한다.
- 4개는 OpenJLPT N5 목록에 없으나 개별 일본어 자료로 일본어 표기·읽기를 확인했다.
- `上がる`의 급수는 N5-1 연구 자료와 OpenJLPT 사이에 이견이 있다.
- 한자 한국식 훈음, 한국어 풀이와 예문은 최종 독립 사전/편집 검수가 남아 있다.
- N5~N1 전체 자동 수입은 다운로드한 OpenJLPT JSON을 인자로 받는 구축 스크립트로 지원하되, 자료 전체의 한국어 번역/검수를 자동 완료했다고 주장하지 않는다.
