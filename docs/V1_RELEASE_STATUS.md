# V1 미리보기 배포 검증

버전: `1.0.13+14` / 태그: `v1.0.13-beta.1` / 검사일: 2026-10-28.

## 제공 기능

N5~N1 오프라인 단어·한자, 가나 표, 활용 문법, 급수별 진도와 첫 미학습 항목으로 이어서 학습, 단어·한자 선택 테스트, 학습 표시와 선택 해제, 별표, 예문·해석 펼치기와 관련 항목 이동, 기기 일본어 TTS, 개인 기록 백업·복원을 제공합니다. 앱 기능은 1.0.12와 같으며 이번 버전은 공개 배포용 서명·패키징·문서를 정비했습니다.

## 검증 결과

- `flutter analyze`: 문제 없음.
- `flutter test`: **62개 통과**.
- Python `unittest`: **33개 통과**. 기존 31개와 공개 소스 패키징의 비밀 파일 제외/차단 2개를 포함합니다.
- 파이프라인 fixture self-test: 통과. 전체 DB audit: SQLite 무결성 정상, 외래 키 오류 0, 한국어 필드 누락 0.
- 범용 release APK: **67,562,784 bytes**, ARM64 release APK: **32,745,833 bytes**. 두 빌드 성공.
- APK 서명 검증: 모두 같은 RSA 4096 배포 인증서, `debuggable=false`, AOT `libapp.so` 포함. debug용 `kernel_blob.bin` 없음.
- 서명 설정 누락 검사: `key.properties`가 없으면 release 빌드를 명시적으로 차단하는 것을 확인했습니다. 확인 후 개인 설정을 복원했습니다.
- APK 내 콘텐츠 DB SHA-256과 원본 DB 일치, ABI 범용 3종 / ARM64 1종 확인. [기계 판독 검증 결과](../reports/v1-release-verification.json).
- 별도의 Android API 36 x86_64 에뮬레이터에 범용 release APK 새 설치. Wi-Fi·모바일 데이터를 끈 상태에서 홈·N5 목록·기본 정답 숨김·정답 표시와 한국어 뜻, 프로세스 재시작 후 학습 완료 유지, 한자 급수·진도 화면을 확인했습니다. 기존 개인 학습 앱을 삭제하거나 데이터 초기화하지 않았습니다.
- 데이터 엄격 검수 게이트: **종료 코드 2**, 콘텐츠 검수 요건 미충족에 따른 미리보기 상태.

ARM64판은 APK 구조·서명·포함 데이터까지 검증했으며 실제 ARM64 기기 실행은 확인하지 않았습니다. 테스트와 빌드를 동시에 실행했을 때 테스트용 플러그인 자동 생성 파일이 섞여 ARM64 빌드가 실패했고, 테스트 종료 뒤 배포용 파일을 재생성해 정상 빌드했습니다. 현재 SDK에서 플러그인의 구형 Kotlin Gradle 사용 경고가 있으므로 향후 Flutter 업그레이드 시 재확인이 필요합니다.

배포 인증서 SHA-256: `a71b6325a89017b0ab7dedb1a4f0f12d71217220446f8981896626002211d8b6`.

## 콘텐츠 검수 범위

단어 7,811개, 급수 한자 2,383자와 보충 한자 159자, 예문 13,718개를 포함합니다. 한국어 뜻·훈음·예문 번역은 전체 입력되어 있습니다. 12,615개 고유 예문 문장쌍에 대해 AI 검토를 했으며 3,819쌍(4,134행)을 교정했습니다.

독립된 사람 검수는 완료되지 않았습니다. 일본어 원문 확인 94건(예문 ID 97개), JMdict 조합 미발견 21개·ID 불일치 2개가 남아 있습니다. DB의 `draft` / `not_verified` 상태와 검수 근거를 보존합니다. 엄격 게이트의 승인 단어 0개는 모든 단어가 틀렸다는 뜻이 아니라, 모든 필수 사람 검수 요건을 충족한 항목이 없다는 의미입니다.

## 아직 확인하지 않은 범위
